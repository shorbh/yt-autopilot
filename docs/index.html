yt-autopilot

Personal automation tool for the Money Mechanics YouTube channel.

yt-autopilot is a private, single-user tool that produces and schedules educational personal-finance videos for one YouTube channel owned by its developer. It uses the YouTube Data API and YouTube Analytics API solely to upload videos to that channel and to read that channel's own performance statistics.

It is not offered as a service to other users and does not collect any data from anyone other than the channel owner.
