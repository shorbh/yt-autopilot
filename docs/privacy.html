Privacy Policy

Effective 17 September 2026

What yt-autopilot is

yt-autopilot is a personal automation tool operated by its developer to publish videos to a single YouTube channel that the developer owns. It is not a public service and has no users other than the developer.

Data accessed

Through Google OAuth, the tool requests permission to (1) upload and manage videos on the developer's own YouTube channel and (2) read YouTube Analytics reports for that same channel. It does not access Google account data of any other person, and it does not read, collect or store viewer personal data.

How data is used and stored

OAuth credentials are stored as encrypted secrets in the developer's GitHub Actions environment and are used only to perform uploads and read channel statistics. Aggregate channel statistics (views, watch time) are used to choose future video topics. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

yt-autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
