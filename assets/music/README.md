# Background music (optional)

Drop royalty-free `.mp3` / `.m4a` tracks in this folder and set `video.music: true` in `config.yaml`.
One track is picked at random per video, looped, and mixed at −20 dB under the voice.

Free, safe sources: YouTube Audio Library (Studio → Audio library, filter "Attribution not required"),
Pixabay Music, Free Music Archive (CC0). Prefer calm, lyric-free ambient/lo-fi at 60–90 BPM.
